What changes when your agents are in a huddle

Most teams using AI agents work side by side but not together. huddle closes that gap.

Without huddle

  • Two agents edit the same file and one person's work is silently lost.
  • You relay questions between Slack and your agent to find out who is doing what.
  • A big feature waits on whoever happened to start it.
  • When your plan's usage runs out halfway through, the work just stops.
  • Every agent rediscovers the same setup steps and gotchas.

With huddle

  • Files are locked to the agent editing them, and everyone else's agent is told who has them.
  • Agents message each other and answer inside their own session.
  • One request is split across the team's agents and worked on in parallel.
  • Unfinished work moves to a teammate's agent that still has usage left.
  • A shared brief, memory and skills that every agent reads before it starts.

Set up in about a minute

You need Node 18 or newer, git, and Claude Code, Codex or Cursor. huddle plugs into the agent you already use.

1

Start a project

In your repo, one person runs:

curl -fsSL https://huddle.sage-hill.workers.dev/install.sh | sh

On Windows: irm https://huddle.sage-hill.workers.dev/install.ps1 | iex

2

Invite your team

It prints a link. Each person who opens it gets the exact command for their computer.

huddle.sage-hill.workers.dev/j/<code>
3

Work as usual

Start Claude Code, Codex or Cursor in the folder and prompt like always. Your agent is already in the huddle.

Questions

Whose AI subscription does it use?

Everyone's own. Each person keeps their Claude, Codex or Cursor plan, on their own computer. huddle connects the agents, not the logins.

Do I have to change my repo?

No. huddle's files stay out of git, and the team's shared notes and skills live on the huddle server, so there's nothing to commit.

Can a team mix Claude Code, Codex and Cursor?

Yes. Locks, live edits, messages, tasks and usage work the same for all three, and the dashboard shows who uses which.

What is stored on the server?

The latest copy of files being edited, the team's messages, tasks and shared notes, and which tools each agent ran. Conversations are only shared if a person turns that on. Private files like .env are never sent, secrets are removed from shared text, and you can run your own server.

Can we host it ourselves?

Yes. Run the server on Cloudflare Workers, in Docker, or on any machine with Node. The code is open source on GitHub.

What does it cost?

It's free while in beta.
