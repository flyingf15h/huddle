How huddle works
huddle lets everyone's Claude work on the same project at the same time, each from their own computer, without stepping on each other's work.

  
    
    
  • See what everyone is doingEach person's card says what they and their Claude are working on right now, and every Claude hears when someone starts something new.
    • 
    
  • Nobody overwrites anybodyA file a Claude is editing is locked for everyone else. A Claude can lock a whole folder before a bigger change.
    • 
    
  • Hand work to the ClaudesGive the whole team a job and one Claude splits it into tasks, or send a request to one person's Claude. Each request runs as its own Claude in the background.
    • 
    
  • Track progressTasks show who owns what and how far along it is. A task closes itself when the commit that finishes it says so.
    • 
    
  • One brief, one memoryThe project brief, team memory and skills reach every Claude when it starts, so nobody has to learn the same thing twice.
    • 
    
  • Code and hand-offsBrowse everyone's shared code, watch edits as they happen, and read where each session left off.
    •
