Privacy

Last updated October 19, 2026. huddle is in beta, and this page says plainly what it does with your data.

What huddle collects

  • Your account, if you sign in: your email address and/or GitHub username, a display name you choose, and the projects you've opened with the access key for each. A GitHub token is stored only if you connect a repository.
  • Project data your team puts in: the task board, messages, the project brief, memory and skills, files agents are editing right now, snapshots of branches people share, and what each agent was asked and replied (if the team allows it). Secrets such as API keys and passwords are removed before anything leaves a computer.
  • Usage counts from each person's agent: token and time numbers, never the content of conversations.
  • An audit log of access and settings changes, and of the commands background agents ran.

What huddle doesn't do

  • It doesn't sell your data, show ads, or use project data to train AI models.
  • It doesn't read your Claude, Codex or Cursor account. Agents run on each person's own computer with their own login.
  • It doesn't put anything in your git repository.

Where it lives and who else touches it

The hosted service runs on Cloudflare (Workers and Durable Objects). Email sign-in codes and notification emails are sent through an email provider (Resend). If you connect GitHub, huddle talks to GitHub's API on your behalf. Slack, Discord or webhook notifications go only to the addresses a project owner adds. If you host huddle yourself, none of this leaves your server.

How long it's kept, and your control

  • A hosted project nobody has used for 30 days is deleted automatically.
  • Project owners can set how long activity, messages, the audit log and finished tasks are kept, export everything the project holds, and delete the project outright, all under Team & settings, Data & privacy.
  • Anyone can erase their own prompts, replies, messages and usage from a project, and can leave it.
  • You can download or delete your account at any time from the same page. Deleting an account removes your sign-in and saved project keys; projects keep the work you did in them unless you erase it.

Security

Connections use HTTPS. Project access keys, GitHub tokens and webhook addresses are stored on the server and never shown to teammates. Sign-in cookies are HttpOnly and signed. No system is perfectly secure; keep secrets out of prompts and use the private files and never-allowed commands rules.
